# 使用手册

按左侧真实菜单逐功能说明。每节：**入口、前置、步骤、期望画面、失败处理**。安装见 [install.md](install.md)。交流合作见仓库 README「交流合作」（微信 **山君**）。

本系统是投研工作台，**默认不下单**。输出不构成投资建议；数据可能延迟。

术语：智能分析 / 快速分析 / K 线分析 / 点数 / L2 委托队列（opt-in）/ Qlib 桥。不要混用「专业 K 线」「Nova Trading Agents」。

---

## 1. 登录 / 改密 / 账户与点数

**入口：** 未登录打开 `http://127.0.0.1:8000` → `/login`。登录后侧栏 **账户**（`/account`）。顶栏头像可退出、进管理后台（管理员）。

**前置：** 已按安装文档启动。黄金路径默认管理员 `admin` / `TA_ADMIN_PASSWORD`（文档示例 `ChangeMe_Admin1!`）。`TA_ALLOW_REGISTRATION=0` 时没有注册入口可用。

**步骤：**

1. 用户名或邮箱填 `admin`，密码填 `.env` 中的管理员口令，点 **登录**。
2. 成功后会进入 **智能分析**（`/analysis`）。
3. 打开 **账户**：可改显示名、邮箱；**修改密码**（旧密码 + 新密码，新密码同样要字母+数字且 ≥8 位）。
4. 同一页查看 **点数**、套餐码、订阅到期；可创建 **API Token**（只显示一次明文，用于脚本 `Authorization: Bearer`）。

**期望：** 登录后左侧出现「控制台、智能分析、快速分析、K线分析…」。账户页能看到点数数字（默认管理员赠点较多）。

**失败：**

- 「无法连接后端」：你开的不是 `http://127.0.0.1:8000`，或 uvicorn 已停。不要用 5173 当黄金路径。
- 密码错误：核对 `.env`，或在仓库根运行 `uv run python scripts/reset_admin_password.py`（仍读 `.env`）。
- 需要改密但强度不够：补字母和数字。

## 2. 智能分析

**入口：** 侧栏 **智能分析** → `/analysis`。

**前置：** `TA_API_KEY`（或设置页保存的用户级 Key）+ 建议 `TUSHARE_TOKEN`。未配 Key 时提交会失败，但画布仍在。消耗点数：`TA_COST_ANALYSIS`（默认环境约 10 点，以设置为准）。点数不足会 402。

**步骤：**

1. 使用**左侧对话**：输入自然语言，例如「调研贵州茅台短线」或代码 `600519.SH`。无需先填复杂表单。
2. 提交后右侧出现 **工作流画布**（分析师 → 辩论 → 交易员 → 风控）。进行中节点会高亮。
3. 点击 Agent 卡片打开 **辩论 Drawer**：多空 / 风控按轮次流式展示。
4. 完成后下方/右侧出现 **研报** 与 **决策卡片**（方向、置信度、目标价/止损若模型给出）。
5. 打开 **数据源** 弹窗，查看本次用到的 vendor / 类目。L2 未开通时相关项为空或软失败，**分析仍应结束**，不要当成系统崩溃。

**期望：** 能看到 15 名角色相关节点（七分析师含量价 + 多空 + 总监 + 交易员 + 三风控 + 裁决）。研报可滚动阅读。

**失败：**

- 无 Key：到 **设置** 保存厂商与 Key，或在 `.env` 填 `TA_API_KEY` 后重启。
- 一直转圈：任务中心看任务状态；网络 LLM 超时属环境问题，手册已覆盖。
- 空白画布：刷新；确认已登录。

截图参考：`assets/web/analysis.png`、`assets/web/debate_drawer.png`、`assets/web/detail.png`。

## 3. 快速分析

**入口：** 侧栏 **快速分析** → `/analysis/fast`。

**前置：** `.env` 中 `TA_FAST_ANALYSIS_ENABLED=1`（示例文件默认 0）。需要 LLM；扣点见 `TA_FAST_COST_POINTS`。未开开关时页面可能提示不可用或提交失败。

**步骤：**

1. 输入标的（如 `600519.SH`），可选意图说明，选择风险偏好。
2. 提交，等待进度条与结论卡（方向/摘要）。可从「最近」列表打开历史快分析。

**期望：** 短链路结论卡，不是完整 15 人辩论。

**失败：** 开关未开 → 在 `.env` 设 `TA_FAST_ANALYSIS_ENABLED=1` 并重启。无 Key 与智能分析相同。

截图参考：`assets/web/fast-analysis.png`。

## 4. K 线分析

**入口：** 侧栏 **K线分析** → `/chart`。历史研报上也可「在 K 线分析中打开」。

**前置：** 日 K 等走行情源（Tushare/AkShare 等，视配置）。**分时 / 五档盘口** 需要账户权益 `advanced_market` 或 `tushare_rt`（管理员默认可见高级能力；普通用户视套餐）。Ai 助手需要 LLM。

**步骤：**

1. 工具栏输入或搜索标的，确认主图蜡烛与报价。
2. 切换周期（如日 K）、复权。交易时段日 K 可能定时刷新（非交易所毫秒级）。
3. 打开 **Ai 盘面解读 / 开始解读**（专业模式），阅读趋势/均线/量能等章节。
4. 若有权限：查看分时、五档盘口。无权限时控件不可用或数据为空——这是预期，不是安装失败。

**期望：** ChartPro 主图 + 周期 + 报价。不要当成 Level-2 交易终端。

**失败：** 无 K 线数据 → 检查 `TUSHARE_TOKEN` / 网络；无盘口 → 权益未开通，见下节 L2。

截图参考：`assets/web/chartpro.png`。

## 5. 自选与定时分析

**入口：** 侧栏 **自选 & 定时** → `/portfolio`。

**前置：** 已登录。定时任务需要分析链路可用（Key + 点数）。

**步骤：**

1. 添加自选代码；可批量导入。
2. 为标的打开 **定时分析**（周期、触发时间）。可批量更新、删除、手动测试。
3. 定时失败多次会自动停用——到本页查看状态。

**期望：** 列表持久化；控制台可能显示定时摘要。参考图 `assets/web/timer_analysis.png`。

**失败：** 测试触发无报告 → 同智能分析缺 Key/点数。

## 6. 持仓与跟踪看板

**入口：** **跟踪看板** `/tracking-board`；持仓导入也在自选页（截图识别需 VLM Key，见 `.env.example` `TA_VLM_*`）。另有 **实时盘** `/realtime-board`。

**前置：** 可手工录入持仓。截图导入需要 `TA_VLM_API_KEY`。

**步骤：**

1. 导入或录入持仓（成本、数量）。
2. 打开跟踪看板：价格、当日区间、盈亏、上一交易日报告区间。
3. 可将持仓同步到定时分析。

**期望：** 看板有数字行，而不是空白崩溃。无行情时价格可能空。

**失败：** VLM 未配 → 用手输。行情空 → token/权限。

## 7. 历史研报

**入口：** **历史报告** `/reports`。

**步骤：** 按标的/日期浏览；打开详情；可跳转 K 线；可删除本机记录。

**期望：** 空库时列表为空。跑过智能分析后出现卡片。参考 `assets/web/reports.png`。

---

## 8. 任务中心

**入口：** **任务中心** `/tasks`。

**前置：** `TA_USER_TASK_QUEUE_ENABLED` 默认开启。若设为 `0`，本页能力关闭。

**步骤：** 查看排队/运行/失败的分析任务；必要时取消或重试（以界面按钮为准）。

**期望：** 提交智能分析后这里能看到对应任务。

---

## 9. 设置（模型厂商）

**入口：** **设置** `/settings`。参考 `assets/web/settings.png`。

**步骤：** 选择厂商（OpenAI / DeepSeek / 智谱等），填写 Key 与模型名并保存。可 warmup 或发「你好」探活。

**期望：** 保存成功；之后智能分析走该配置。

**失败：** Key 无效由厂商返回错误。不要把 Key 贴到 GitHub Issue。

---

## 10. 管理后台（浏览级）

**入口：** 顶栏管理员入口 → `/admin`（用户/套餐/审计等）。默认进报表总览。

**前置：** `role=admin`。

**步骤：** 打开 **用户** 列表，确认只有你创建的管理员（空库）。浏览 **套餐**，不要在验收时随便改生产计费。

**期望：** 能进入后台；用户表干净。

---

## L2 委托队列（opt-in）

**不是开箱即 L2。** `.env` 默认 `TA_TUSHARE_L2_ENABLED=0`。

1. 你的 Tushare 账号须有 L2 / 委托队列类权限。
2. 设 `TA_TUSHARE_L2_ENABLED=1`（可选 `TA_TUSHARE_L2_API`），重启 API。
3. 在智能分析 **数据源** 弹窗或 K 线高级盘口查看是否命中。无权限时为空，分析继续。

---

## Qlib 桥（可选）

默认关闭（`TA_QLIB_*_ENABLED=0`）。Docker **不含** Qlib。若本机打开桥接且界面有入口，按界面操作；否则只把 Qlib 当作能力说明，见 [capabilities.md](capabilities.md)。
