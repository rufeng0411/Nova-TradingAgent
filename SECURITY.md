# Security policy

Do **not** file public issues for vulnerabilities.

- Use GitHub private vulnerability reporting on this repository.
- Or email the maintainer via the GitHub profile of `rufeng0411`.

We aim to acknowledge reports within 14 days. This is not an SLA.
