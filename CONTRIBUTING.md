# Contributing

Please **open a discussion or issue before a large PR**. Small docs/typo fixes can go straight to a pull request.

1. Fork and clone `https://github.com/rufeng0411/Nova-TradingAgent.git`
2. Follow [docs/en/install.md](docs/en/install.md) for a SQLite boot (port 8000, `GET /healthz`).
3. Prefer focused pytest files under `tests/` rather than live Playwright against production.
4. Open a PR against `main` using Conventional Commits (`feat:`, `fix:`, `docs:`).

**Do not paste API keys, Tushare tokens, or `.env` contents** into issues, PRs, or screenshots.
