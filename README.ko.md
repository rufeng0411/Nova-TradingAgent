**Fifteen specialists. One A-share research desk.**

업스트림 TradingAgents 토론 그래프를 로그인 가능한 웹 리서치 데스크로 만든 프로젝트입니다. ChartPro, 빠른 분석, 선택적 Tushare L2, 선택적 Qlib 브리지, 다중 사용자 크레딧/관리 콘솔을 추가했습니다. 기본값은 자동 주문이 아닙니다.

제품 소개와 원본 대비 차이는 [简体中文 README](README.zh-CN.md)와 [English README](README.md)가 정본입니다. 설치는 [docs/zh-CN/install.md](docs/zh-CN/install.md). 헬스 체크는 `GET /healthz`입니다.
